I had to rush out of the house with an active Claude Code session running on my laptop. Out of curiosity more than expectation, I opened the Claude app on my phone, logged into the same account, and found the exact same session still running.

---

## Not a copy — the same session

This wasn't a synced version or a snapshot. It was literally the same session, streaming its conversation to my phone in real time, while all the code and files stayed on the laptop.

That distinction matters. It's not cloud coding, where the work itself moves to a remote machine. It's more like your phone becomes a window into a session that's still fully running at home — you can watch it think, steer it, and step in when it needs a decision, all without the work ever leaving the machine it started on.

---

## The one catch

Your laptop has to stay awake and connected, since the actual work happens there. The phone is a control surface, not a runtime — lose the laptop's connection and the window goes dark until it's back.
